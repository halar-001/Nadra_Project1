PART II: Backend Component Testing (Spring Boot)

1. Core Security Layer (SecurityConfig, JwtService, JwtAuthFilter)

Handles stateless authentication, role enforcement, and token lifecycles.

Test Parameter Expected Outcome Status
Stateless Protection All /api/** endpoints (except auth) strictly require valid Bearer tokens. Invalid tokens throw 401. PASS
Server Restart Invalidation Tokens timestamped before application boot (`SERVER_START_TIME`) are actively denied. PASS
Role Enforcement Endpoints annotated with @PreAuthorize("hasRole('ADMIN')") successfully block Viewer accounts. PASS

2. Connection & Schema Services (ConnectionService, SchemaService)

Manages encrypted JDBC credentials and extracts database metadata safely.

Test Parameter Expected Outcome Status
IDOR Prevention Modifications require findByIdAndUserId. Cross-account tampering is completely blocked. PASS
JDBC Factory Constructs isolated JDBC connections dynamically based on provided DTOs without leaking resources. PASS
Safe Schema Extraction Extracts DB metadata (Tables/Columns) using standard JDBC DatabaseMetaData classes, avoiding SQL Injection vulnerabilities. PASS

3. AI Query Pipeline (QueryPipelineService, PromptBuilder, LlmClient)
